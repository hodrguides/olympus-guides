# Olympus Guides
Guías y calculadoras para Olympus (NosTale). HTML/CSS/JS puro, sin compilación.

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a un repositorio.
2. Settings > Pages > Deploy from a branch > `main` / `(root)`.
3. Pon tu imagen en `assets/hodr.png` y cambia los enlaces marcados con TODO en `index.html`.

## Probar en local
Los textos se cargan con `fetch`, así que no abras el HTML con doble clic. Usa:
`python3 -m http.server` y entra en http://localhost:8000
